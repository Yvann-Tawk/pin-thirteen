# Contributing

1. Run the checks in the README before opening a pull request.
2. Keep pure packages free of React and browser storage.
3. Sign off commits with `git commit -s` (Developer Certificate of Origin).
4. Adding a component: add one file in `packages/registry/src/components/`, then register it. The generic registry tests cover it automatically.
5. Write original teaching content. Do not copy from arduino.cc, which is CC BY-SA.
